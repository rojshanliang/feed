SPEC · 消息页结构说明（互动消息筛选模式）

消息来源 互动消息 · 无创作者/用户私信 · 无聊天功能
通知类型（新增） 大舞台 点赞评论回复打赏
通知类型（原有，不变） 点赞（逐条）· 新增关注（逐条）· 评论（逐条）· @提及
展示方式 与原有一致：单一列表，按日期分组（今天/昨天）+ 组内时间倒序；大舞台相关通知直接插入同一列表，不新增 Tab、不新增分组
来源标识 仅大舞台来源的互动通知在昵称右侧附加深色「大舞台」标签（复用话题页卡片来源角标样式）；图文/视频来源的互动通知不加标签，沿用原有约定
通知图标 按类型区分背景色圆角块：蓝（系统）红（点赞）绿（关注）黄（评论/提及）暖（公告/打赏）紫（回复），新增类型延续原有配色逻辑
打赏信息展示 礼物名称以 🧸 玩偶 黄底徽标展示（与大舞台页/详情页 .gift-name 样式一致）+ 数量 ×N，互动类和交易类通知均展示同一形式，不展示价格数字
是否合并 点赞合并为一条「XX、YY 等 N 人赞了你的大舞台动态」；评论/回复/打赏逐条展示，不合并——三者均带有独立的具体信息（内容预览/礼物/回复对象），合并会丢失信息
回复通知格式 朋友圈式 C 回复 B：文案为「XX 回复了你的评论：「回复内容」」，与评论通知同规格的单行文字展示，不额外增加引用区块
跳转行为 点击大舞台点赞/评论/回复/打赏通知，进入对应大舞台动态详情页（square-detail-wireframe-mp.html）
未读状态 右侧红点 · 文字加重，与原有约定一致
缩略图 与内容相关的通知（点赞/评论/打赏）展示对应动态缩略图占位；回复/系统类通知不展示缩略图
空状态 铃铛图标 + 「暂无消息」+ 说明文字，与原有一致
