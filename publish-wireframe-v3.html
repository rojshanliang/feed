SPEC · 发布器结构与交互规范说明

发布器交互形态 移除顶部内容类型 Tab，直截呈现统一发布器：如朋友圈般一站式支持 纯文字图文（文字+图片）视频（文字+视频） 发布，无需预选模式
发布形式 与朋友圈一致：纯文字图文（文字+图片）视频（文字+视频） 三种，无需分 Tab 选择，由是否添加媒体决定
正文输入 大段文字输入区（占位「这一刻的想法…」），最多 1000 字，键入 # 内联识别话题；允许完全为空媒体、仅发文字
发表情 正文下方一个表情按钮，点击后展开表情面板，选中的表情插入到光标处，与图片/视频输入互不影响，可与文字任意组合
⑩ 表情面板中 点击表情按钮后，原位置展开 8 列表情网格，再点一次收起；面板展开状态下仍可继续切换图片/视频媒体类型
图片 / 视频互斥 「图片」「视频」两个媒体入口二选一：选中一种后另一种禁用（灰色不可点），与文字任意组合，不能同时发图片和视频
图片 3 列宫格 · 最多 9 张 · 每张右上角可删除，上传中显示旋转加载圈 + 百分比 + 进度条
⑨ 视频态（加号选视频） 点击媒体动作「视频」后展示视频管理区：未添加时呈现标准 ＋ 选择视频 卡槽；点击加号直接打开 ⑩ 选择视频 自研相册网格；选定后卡片切换为已选视频缩略图（带播放标识、时长角标与右上角删除「×」），点击「×」可移除并恢复加号卡槽。
⑩ 选择视频（自研相册） 像选择照片一样的自研多媒体相册视图：4 列网格陈列本地视频库，每项带播放标识与时间长度角标（如 00:24、01:15），右上角提供圆形数字勾选框，单选控制（1/1）。
底部操作栏与选择照片保持一致布局：
- 左侧「✨ 一键成片」：直接将勾选的视频/片段导入智能剪辑，进入「⑥ 一键成片」；
- 右侧「下一步 (1/1) ›」：黄色主按钮，确认选定并直接进入「⑪ 视频预览」进行全能剪辑与调色。
⑪ 视频预览（多功能剪辑编辑） 如同图片预览一样的全功能视频预览与编辑主态：
1. 上方大按钮「选择音乐」（位置同「一键成片」一致）：位于导航栏下方、播放视口上方通栏陈列，展示当前背景音乐状态与「选择音乐 ›」入口，点击直达音乐选择半弹层；
2. 中央全屏播放视口：9:16 全屏纯净播放视口，带中央播放/暂停控制与底部实时进度条/时间码（00:10 / 00:24）；
3. 右侧标准悬浮工具组（已去除底部重复工具栏）：告别与右侧功能重叠的底部常驻按钮，所有功能统一由右侧标准悬浮图标唤起底端抽屉：
- 视频滤镜 (🎨)：点击右侧滤镜图标，自底向上滑出滤镜调色抽屉，支持横向切换「原色 / 胶片 / 日系 / 复古 / 黑白」风格；
- 音量混音调节 (🔊)：点击右侧音量图标，滑出「视频原声」与「BGM配乐」独立双轨 0~100 混音抽屉；
- 剪辑选段 (✂️)：点击右侧剪辑图标，滑出时间线胶卷轨道与出入点截取抽屉；
4. 顶部完成按钮：确认编辑效果后点击「完成」，将制作就绪的视频回填至视频发布主态。
发布条件 文字 / 图片 / 视频三者至少填写一项即可发布；媒体上传中禁用发布按钮，直至全部完成
③ 选择照片（自研渲染） 替代传统调用系统相册的黑盒交互，自研照片选择器界面：
1. 顶部导航栏：左侧「取消」（返回图文编辑）、居中相册下拉切换「所有照片 ▼」，无多余按钮保持居中；
2. 4 列沉浸照片网格：无拍摄按钮，纯粹照片多选，右上角圆形数字勾选框（支持 1~9 多选并实时标注序号）；
3. 已选照片预览托盘：位于操作栏上方，自左向右横向展示已勾选照片微缩图（带顺序角标与快捷删除「×」）；
4. 底部操作栏：左侧「✨ 一键成片」，右侧主按钮为「下一步 (4/9) ›」，无中间滤镜按钮，点击直接进入「④ 图片预览」。
④ 图片预览（含移动端工具抽屉） 点击选择照片的「下一步」后进入的大图预览与编辑主态：
1. 中央大图视口：高清全画幅预览当前焦点的照片，支持大图滑动切换与右上角页码指示（如 1 / 4）；
2. 下方全量已选图片栏：底部从左到右横向平铺展示所有已勾选的照片缩略图，点击任意一张可快速切换主屏大图；
3. 移动端标准工具抽屉（Action Sheet）：右侧为「🛠️ 工具」按钮，去除了桌面端气泡式浮层与裁剪/贴纸多余项。点击自底向上滑出规范的半屏暗黑磨砂工具抽屉，内含 🎨 滤镜 大图标功能项，点击即可唤起「⑤ 滤镜调节」面板，未来新增工具可规范向右平铺扩展；
4. 顶部完成按钮：直接完成所有图片选定并返回图文发布编辑主态。
⑤ 滤镜调节（面板展开态） 在图片预览态点击右侧「滤镜」按钮呼出的调色功能样式：
1. 大图视口预览：沉浸式呈现当前照片与所选滤镜的实际效果，支持「按住看原图」实时对比；
2. 滤镜强度滑条：0~100 强度细致微调；
3. 分类与滤镜横滑列表：热门推荐 / 复古胶片 / 日系清透 / 质感高级 / 经典黑白 等预设风格；
4. 批量应用与返回：支持「应用到全部照片」一键统一全套图文风格，点击「完成」保存并返回「④ 图片预览」。
⑥ 一键成片（图文转视频） 点击选择照片底部的 ✨ 一键成片 后进入独立的视频生成与编辑状态，本质为照片自动转场视频：
1. 上方大按钮「选择音乐」：通栏展示当前应用的自带配乐（如「晴天 - 周杰伦」），支持点击打开音乐选择半弹层更换 BGM；
2. 中央播放主体视口：竖版视频播放窗口，预览已选照片在当前模板下的运镜、转场效果及进度条/时长；
3. 下方横向滑动模板库：支持左右手势滑动选择不同剪辑模板（如 气氛感日云海、照片欢快卡点、快乐是什么、胶片复古日常等）；
4. 默认选中模板带「编辑」状态：当前选中的模板卡片上附带「✏️ 编辑片段」入口，点击即可呼出「⑤ 模板编辑」微调半弹层；
5. 最下方操作栏「下一步」：确认模板与成片效果后，点击「下一步」直接带入视频发布态进行最终标题与权限设置并发布。
⑦ 模板编辑（半弹层） 点击「✏️ 编辑片段」弹出的底端操作弹层（仿剪辑行业标杆规范）：
1. 弹层顶栏：左侧取消「✕」、居中「模板编辑」、右侧确认「✓」；
2. 横向片段列表：展示构成视频的各个镜头切片，精确标注时长（如 1.1秒、0.9秒、1.3秒、波形卡点），高亮白框指示当前焦点片段；
3. 底部操作功能：
- 「⇄ 替换素材」：点击后直接跳转链接到「③ 选择照片」自研相册状态，重新选取照片替换当前焦点片段。
⑧ 选择音乐（半弹层） 点击图文九宫格加号旁边的 选择音乐 卡槽后，自底向上滑出 70% 高度半弹层。弹层内集成：
1. 顶部拖拽手柄、居中标题「选择音乐」与右上角关闭「×」；
2. 搜索框：支持搜索歌曲、歌手或氛围标签；
3. 分类 Tab：横向切换「推荐 / 热门流行 / 治愈系 / 节奏欢快 / 我的喜欢」等；
4. 音乐列表：单行展示封面微缩图、歌曲名、歌手与标签、试听时长（0:30~0:45）及「使用」按钮；点击「使用」或单行即可完成选中并关闭弹层返回图文态，卡槽切换为「已选: 曲目名」并带黄边高亮。
