SPEC · 打赏额度模块结构说明（个人页 / 创作者页）

打赏额度卡 位于数据四格（关注/粉丝/获赞/内容）下方、操作按钮上方 · 独立卡片，1px 描边 + 6px 圆角
数据展示 七日打赏额度总打赏额度 两项并列，金额用等宽数字（IBM Plex Mono），不带货币符号（打赏为虚拟礼物，非真实货币）
不重复展示 页面本身已展示头像与昵称，打赏卡内不再重复出现创作者信息
适用范围 个人页创作者页 均展示，数值随粉丝量级同比放大
与原页面差异 在 profile-content-tab-wireframe-mp.html 基础上新增本模块，其余结构保持一致；个人页移除「编辑个人资料」按钮
分享入口（已移除） 个人页 NavBar 右上角、创作者页 NavBar 右上角、创作者页「+关注」按钮旁均移除原有分享（↗）图标；个人页保留消息（✉）与设置（⚙）入口，创作者页 NavBar 右侧改为等宽占位以保持标题居中
消息入口未读角标 个人页 NavBar 消息（✉）图标右上角常驻叠加红色圆形数字角标，提示未读消息数（示例值 12）；角标随未读数增减实时更新，全部查看后消失；已直接采纳进①态，不再单独拆分状态验证

SPEC · 广场 Tab 结构说明（个人页 / 创作者页）

Tab 位置 内容 Tab 由「视频 / 图文」扩展为「视频 / 图文 / 广场」三个 Tab，广场为第三项
卡片样式（仿照微信「相册时光轴」，本次核心变更） 改为单列时光轴样式：左侧日期角标（日期大字号 + 月份小字号）+ 中间小尺寸缩略图（纯文字动态无缩略图）+ 右侧纯文案摘要（最多 3 行截断，仅展示动态正文，不展示点赞/打赏/评论数量）；不再展示头像、昵称、图片九宫格、视频竖版大图、「···」互动菜单、点赞打赏评论摘要信息条、右侧指向箭头
动态形式 纯文字单图+文字多图+文字视频+文字 四种形式共用同一时光轴卡片结构，单列时间倒序排列；纯文字无缩略图，单图/视频缩略图为单格填满（视频右下角叠加时长角标）
多图缩略图拆分规则（见参考图 image-17.png / image-20.png） 同一个 64×64 缩略图大方块按图片数量（2~9 张，9 张为上限）拆分成对应的小方块拼贴，而非单张缩略图+数字角标：2 张左右两栅等分；3 张左侧 1 张竖图占满整高 + 右侧 2 张上下堆叠；4 张四宫格平分；5 张2 行×3 列网格，末位 1 格留空；6 张左侧 1 张大图占满左上 2×2 + 右上 2 张小图上下堆叠 + 底部 3 张小图横排一行（非等分网格，与参考图一致）；7 张3 行×3 列网格，末位 2 格留空；8 张3 行×3 列网格，末位 1 格留空；9 张3 行×3 列网格，恰好铺满
卡片点击行为 整条动态卡片可点击，点击后跳转至独立的动态详情页（square-detail-wireframe-mp.html，本图未展示），在详情页内查看完整正文、图片/视频、点赞头像墙、打赏明细、评论列表及回复、点赞/评论/打赏操作入口；列表页卡片内不再提供任何互动操作，也不再就地展开完整互动信息
适用范围 个人页创作者页 均展示，样式完全一致，仅摘要文字与数据量级不同
