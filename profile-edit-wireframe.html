SPEC · 个人资料编辑页结构说明

编辑资料入口 「我的」页头图下方右侧 · 胶囊按钮「✎ 编辑资料」
入口去向 进入编辑页（已有资料 → 已填写状态）· 返回 / 保存均回到「我的」
「我的」页来源 整合自 creator-center-matrix.html · 保留等级半屏 / 打赏卡 / 内容 Tab / 侧边抽屉
「我的」导航栏 左：汉堡菜单（抽屉从左滑出）· 中：标题 · 右：胶囊（仅关闭）
关闭确认 点胶囊「关闭」→ 弹窗「退出小程序？」· 取消 / 退出
顶部导航 NavBar（返回 / 编辑个人资料 / 保存按钮）
个人页头图 120px 高横幅 · 点击「更换头图」触发图片选择
头像 64px 圆形 · 叠加在头图下方 · 右下角编辑点触发选择
用户昵称 可编辑 · 支持中文 · 不做唯一性校验 · 点击进入文字输入页
ID号 不可更改 · 编辑页不展示 · 仅在「我的」页展示
简介 多行文本 · 点击进入文本编辑页 · 最多展示 3 行
